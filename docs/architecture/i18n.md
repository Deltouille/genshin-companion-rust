# Texts in every language

The app speaks English and French. **Every text a player reads is a [Fluent](https://projectfluent.org) message**,
the interface's and the core's own: never a literal in a view, never `format!` of words.

## The interface's texts

```text
crates/<crate>/locales/<code>/<part>.ftl     en/ and fr/, one .ftl per part
```

| Crate | Parts | Macro |
| --- | --- | --- |
| `wish-core` | `core` (errors, import and sync notes, banner types, roles, resin sources…) | `t!` in `crates/wish-core/src/lib.rs` |
| `wish-ui` | `ui` (formatting, servers, weekdays, rate-up results…) | `t!` in `crates/wish-ui/src/lib.rs` |
| `wish-app` | `app`, `archive`, `credits`, `history`, `import`, `imports`, `overview`, `planner`, `settings` | `t!` in `crates/wish-app/src/lib.rs` |

Each crate declares its parts with `texts!(…)` into a `Texts` of its own and looks a message up with
`t!("key", name = value)` over `tr!` (`crates/wish-core/src/i18n/mod.rs`).

- **Pass numbers as numbers.** Fluent picks the plural (`{ $count -> [one] … *[other] … }`), formats the number
  with the language's separators, and `NUMBER($x, minimumFractionDigits: 1)` gives decimals. The message, not the
  code, orders the words.
- **The key is a literal**, so the check below can find every one the code names.
- **French typography**: a no-break space (U+00A0, or the narrow U+202F) before `? ! : ;` and inside « », the curly
  apostrophe ’. Formal "vous".

### The checks

Each crate has a `…_texts_are_complete` test calling `i18n::check::check`: every key in every language with the
same variables; every key the code names exists in English with the variables the code passes; no key unused;
every text formats; the French typography. A missing translation fails the tests, not the player.

### One language for the process

`language()` / `set_language` (`i18n/mod.rs`). `main` reads `Settings::language` alone, before the first message
or window (`Settings::read_language`); `None` follows the system (`Language::system()`), and a code this version
doesn't know reads as `None`. Settings changes it through `Preferences::set_language` → `crate::apply_language`,
which sets GPUI Kit's locale, the menus, and redraws every window. Text worked out ahead of a render (a page's
model, a picker's options) is worked out again when the library notifies, which the change of setting does.

Tests use `with_language` (thread-local), never `set_language`: they run side by side.

### Formatting

- Numbers: `wish_core::i18n::number` (`integer`, `decimal`: `12 800,5` in French).
- Everything else a page shows: `crates/wish-ui/src/format.rs`: sizes, dates (`date`, `date_time`, `month_year`,
  `weekday`…), quotes, servers (`server`), `capitalize` (a core error, which starts lowercase, as a sentence), the
  game's fixed terms (`element`, `weapon_type`, `stat`, from the data's English). Never chrono's `format("%b")` for
  a player: its names are English.

### Errors

`wish_core::Error`'s `Display` reads `error-…` messages from `core.ftl` (`IoAction` names what was being done to a
file). A message says what happened and what the player can do ("update the app"), never a developer's step (a
command, a script); a test checks it.

## The game's own texts

The game's names and descriptions (characters, talents, constellations, weapons, passives, materials, domains) come
in every language from `crates/wish-core/data/fr.json` beside the English in `planner.json` and `archive.json`
([game-data.md](game-data.md)). They merge as the data loads into a `Text` (`i18n/text.rs`), which reads (`Deref`,
`Display`) in the current language, else English.

- **Match what the game, HoYoLAB or a file says against `Text::english()`** (the sync's talent names, GOOD keys); a
  name the player typed against `Text::matches` (any language). `Text` has no `==` with a string, so the compiler
  shows every comparison.
- The wish history stores English names, as the game's API sends them (`lang=en-us`); `i18n::game::item_name`
  shows one in the current language.
- Account names imports create ("Main", "Account 3") stay English: imports find accounts again by them.

## Adding a language

1. A `Language` variant (`code`, `name`, `from_locale`) in `crates/wish-core/src/i18n/mod.rs`.
2. Every `.ftl` of every crate under `locales/<code>/`; the checks list what's missing.
3. The game's texts: add the language to `LANGUAGES` in `tools/extract-genshin-db.mjs`, add it to genshin-db's
   sparse checkout, run the script, embed the new `data/<code>.json` in `i18n/game.rs`.
4. Its number formatting in `i18n/number.rs` if it differs, and the README's Languages section.

Banner names stay English for now: paimon.moe has them in English only.
